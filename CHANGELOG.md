# Changelog

## v1.0.0 (2026-05-29)

### Core Analysis
- Research Readiness Dashboard with quality gates and severity scoring
- Per-scale Cronbach's α with standardized α and ω
- Item-total correlation and α-if-deleted diagnostics
- KMO and Bartlett's test of sphericity
- Exploratory Factor Analysis with varimax rotation, scree plots, and loading matrices
- Bootstrap stability with recommended sample size estimation
- Scale-level correlation matrix with construct relationship interpretation

### Workflow
- Quick Mode for instant analysis of auto-detected Likert items
- Custom Mode for user-defined composites, scales, and variable selection
- Analysis scope lock — only selected variables enter analysis
- Automatic metadata column filtering (Qualtrics/system fields)
- Codebook upload and auto-mapping (CSV, XLSX, SPSS, PDF, Markdown)
- Missing value strategies (listwise, mean imputation)
- Reverse-item detection and confirmation workflow

### AI & Reporting
- AI Executive Summary with evidence-traceable recommendations
- Multi-provider support (OpenRouter, Anthropic, OpenAI, DeepSeek)
- Bilingual UI and AI output (Chinese / English)

### Export
- PDF report via browser print
- APA results (copy-friendly + downloadable)
- Markdown report with numbered sections
- Quarto report (.qmd)
- Excel workbook with multiple sheets

### Trust & Verification
- Internal verification against reference datasets
- External validation framework (pending R/Jamovi/SPSS)
- Methodology & Trust Center
- Privacy: local-first, no data upload, API key in sessionStorage only

### UI/UX
- Responsive three-column layout
- Language toggle (中文 / EN)
- Dark mode support
- GitHub Star button with live count
